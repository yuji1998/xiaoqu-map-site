# 看房点位交互地图（苏州）

单文件交互式地图，标注苏州 3 处点位与工行苏州分行本部，并给出驾车距离与耗时。

## 点位

| 编号 | 名称 | 地址 | 距本部 |
|---|---|---|---|
| 1 | 万科·玲珑东区 | 玲东花园·东沙湖路与星塘街交汇处东北 | 2.77 km |
| 2 | 白塘景苑 | 金鸡湖街道白塘路55号 | 2.45 km |

| B | 工行苏州分行本部 | 旺墩路122号 | — |

## 使用

- 浏览器直接打开 `index.html` 即可，无需安装、无需服务端。
- 地图可拖动缩放；点标记弹详情；点下方条目自动定位。
- 每条右侧「导航」按钮唤起高德 App 导航（`uri.amap.com`，无需 API Key）。
- **底图需联网**（直连高德官方矢量瓦片）；断网时页面仍可打开，底图为空白。

## 说明

- 距离与耗时为高德 Web 服务 API 实测实时路况，随时间变化，仅供参考。
- 坐标经高德 POI 检索核实。
- 页面为单文件，Leaflet 库已内联，无外部 JS 依赖（仅底图瓦片联网请求）。
- 页面不含任何 API Key 与个人敏感信息。
